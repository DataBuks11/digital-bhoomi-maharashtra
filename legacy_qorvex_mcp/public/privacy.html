Privacy Policy

Effective Date: October 19, 2026
Organization: Virtual Galaxy Infotech Limited (VGIL)
Application: QORVEX — Enterprise AI Connector

1. Overview

Virtual Galaxy Infotech Limited ("VGIL", "we", "us", or "our") operates the QORVEX Enterprise AI Connector ("the Service"). This Service exposes verified corporate data, software product specifications, IT service capabilities, and statutory governance information from the official VGIL web portal (https://vgipl-website.vercel.app/) to authorized AI clients and users.

2. Data Collection and Processing

The Service is designed with strict data minimization principles:

  • No Personal Identifiable Information (PII) Stored: The Service does not collect, record, or retain personal data from users interacting via ChatGPT, MCP clients, or web interfaces.
  • Stateless Search Queries: Queries submitted to the Model Context Protocol (MCP) server or REST endpoints are processed in-memory for the sole purpose of document retrieval and grounding. Queries are not persistently logged or used to train artificial intelligence models.
  • Telemetry Data: System health metrics (such as uptime, total indexed record counts, and service status) contain zero user-identifying information.

3. Third-Party Processors & Infrastructure

When using the natural language assistance features, query text and retrieved excerpts from the public VGIL website are routed via encrypted HTTPS to our configured LLM router provider (TokenHarbor / DeepSeek) solely to assemble grounded answers. No proprietary customer credentials or private data are transmitted.

4. Data Security

All communication with QORVEX occurs over Transport Layer Security (TLS 1.3 / HTTPS). Server-side credentials, API keys, and authorization secrets are strictly isolated on server infrastructure and are never exposed to browser clients, frontend bundles, or third-party loggers.
